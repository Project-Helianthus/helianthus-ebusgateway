## Publish the passive reconstructor only from a live generation

A passive reconstructor built by an eBUS generation that was stopped or replaced while the reconstructor was being constructed is now closed and is not kept for later generations; the next generation builds its own. This applies to both places that build it: the advisory source-selection warmup and the passive observe-first task. Before, the handle was stored on the process context without a liveness check, so a withdrawn generation could leave a passive tap that every later generation reused. A live generation still builds the reconstructor once and later generations reuse it. No configuration or name changes; existing log lines are unchanged, and a failed close of the refused handle is logged. The gateway binary changes.
