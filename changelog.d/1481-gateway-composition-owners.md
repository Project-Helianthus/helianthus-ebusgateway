## Finish the shell: API composition, size guard and the owner contracts page

`runGatewayLifecycle` is now the entry over four documented owners (process shell, API composition, retained consumers, generation owners) and `startHTTPServer` over two surface builders. The new API composition owner, `gatewayAPIComposition`, builds the gateway, the static seed, the GraphQL builder, the address-table inserter, the hub and router plane, the semantic runtime and the late-bound writers in the same order, starts the HTTP control plane through `startHTTPServerFn` and registers its releases in the process-shell shutdown sequence; a test asserts the complete startup and shutdown trace. A test fails on a function over 150 lines or a file over 1,000 lines or 60 functions in these files. A new page, `docs/architecture/gateway-composition-owners.md`, states each owner's contract and the shutdown sequence. Behaviour is unchanged; the gateway binary changes.
