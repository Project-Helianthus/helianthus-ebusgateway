## Adopt the modbusreg Growatt, Tesla and Huawei packages

The modbusreg pin moves to the library's main-branch revision with the Growatt, Tesla and Huawei packages. That revision also moves the SunSpec, Fronius and OutBack families, profile detection and the attempt ledger, so the gateway adopts all eight packages together. The gateway imports `growatt`, `tesla`, `huawei`, `sunspec`, `fronius` and `ledger` from helianthus-modbusreg wherever it used a moved name; it uses no detection or OutBack name. The vendor or owner prefix of each renamed name moves into the package qualifier (`modbusreg.GrowattAggregateAttempt` becomes `growatt.AggregateAttempt`), and names that kept their spelling only change their qualifier. The Fronius flavor selection that was a registry method is now called as `fronius.SelectObservedFlavor` with the registry as its first argument. `scripts/adopt_modbusreg_packages.py` reproduces the rewrite, and `--check` confirms that no moved name is left behind and that every modbusreg import is used. Runtime behaviour, wire values and API surfaces are unchanged; the gateway binary changes.
