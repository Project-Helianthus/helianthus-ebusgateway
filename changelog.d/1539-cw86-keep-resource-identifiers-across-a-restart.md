## Keep resource identifiers across a restart after an anchor supersession

The resource allocator in `internal/semgraph` can now keep its supersession table in one file. `OpenStore(dir)` returns a store backed by `semgraph-anchors.json` in an existing directory, or the in-memory table when no directory is given. The file records every anchor key with its resource, class, basis, parent, slot and supersession state, and the home asset of each resource, so an identifier allocated under an operator label and superseded by a native token is the same after a restart. An absent file is an empty table; a damaged file is refused with `ErrStoreDamaged` and a file of another format or version with `ErrStoreForeign`, and nothing is allocated over either. Each change replaces the file atomically. A supersession of a native token now also compares the parent and slot of the previous anchor with the recorded ones, so the `supersedes` record always names the current anchor. No runtime path opens a file store yet (#1539).
