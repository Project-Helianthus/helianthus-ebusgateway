## Load configured operator records and accept an identity link

Startup loads the operator-record section the configuration already holds, including an identity link that names the home asset, the native resource and the configuration basis class. An empty section still admits nothing. Startup does not declare a home the preflight snapshot does not already name, so a driver that discovers that home can claim it; the identifier's shape is not ownership. A home a driver already owns is not declared again. Its configured set is published when that owner has admitted the provider, and it is reported and left unpublished when the owner has not. A set whose home or starting end is not yet there stays pending. A Portal replacement supersedes relations that were waiting at startup, so a relation the operator removed is not published when its home appears. The provider still does not publish the identity link; that record waits as applied and unpublished. (#1539)
