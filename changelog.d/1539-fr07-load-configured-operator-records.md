## Load configured operator records and accept an identity link

Startup loads the operator-record section the configuration already holds, including an identity link that names the home asset, the native resource and the configuration basis class. An empty section still admits nothing. A configuration-only home is declared for the configuration provider when its identifier is not one a dynamic driver allocates; a home a driver already owns is not given a contributor declaration, and a home a dynamic driver allocates stays undeclared until that driver discovers it. A Portal replacement supersedes relations that were waiting at startup, so a relation the operator removed is not published when its home appears. The provider still does not publish the identity link. (#1539)
