## Carry the proxy-dependent passive cases by matrix cells and start the remaining passive cases the way the add-on does

The passive suite has three cases (`P01`, `P02`, `P06`). `ENS-AD02` and `ENS-AD03` judge required passive discovery with no external client. `ENS-CX01` and `ENH-CX01` judge that discovery while their external clients run in the cell window. The passive gate accepts the three-case report only when those cells show the discovery passed. The passive harness starts the gateway the way the add-on does and fails when the eBUS driver is withheld. Gate and tooling change, the gateway binary changes only through the matrix package.
