## Switch the transport gate's report form to adaptermux-v2 without a run of the retired form

The transport gate accepts an `adaptermux-v2` aggregate report of the AdapterMux conformance matrix and no longer asks for the 88-case form, whose proxy topologies are retired; an 88-case report is rejected with a message that names the new form. The policy page is applied, with the T01 to T08 keepers carried by matrix cells. Pull requests still merge under the standing override until the consolidated session's report exists. Before the new form serves as gate evidence, the matrix runner drives each PX cell with the stimulus of its own invariant, starts a cell's client only after the smoke command has taken its baseline reading, and hands `--ebusd-command-addr` to the cell commands. The smoke command detects a running mux from every family it renders and compares MCP and GraphQL on a stable pair of readings. AD04 and AD09 now fail with the reason that a hold raised between two readings is not provable with a sampled gauge, and measure the resumption from the reading before the discontinuity. Gate and tooling change; the gateway binary is unchanged.
