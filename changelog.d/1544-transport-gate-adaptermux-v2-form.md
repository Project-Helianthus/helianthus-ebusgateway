## Switch the transport gate's report form to adaptermux-v2 without a run of the retired form

The transport gate accepts an `adaptermux-v2` aggregate report of the AdapterMux conformance matrix and no longer asks for the 88-case form, whose proxy topologies are retired; an 88-case report is rejected with a message that names the new form. The policy page is applied, with the T01 to T08 keepers carried by matrix cells, which is the correction criterion recorded on the issue. Pull requests still merge under the standing override until the consolidated session's report exists. Before the new form serves as gate evidence, the matrix runner drives each PX cell with the stimulus of its own invariant, starts a cell's client only after the smoke command has taken its baseline reading, and hands `--ebusd-command-addr` to the cell commands. For PX01 and PX02, the contender writes an INFO request after each START, and the bid counts as forwarded only when a symbol arrives after a SYN that the mux delivered after answering that request, before it is replaced or the session closes: a prompt result makes the contender bid again instead of ending the stimulus, and a queued bid does not count as in flight. The workload after the stimulus bids with a different initiator, and until the absorb bound a STARTED or FAILED naming the replaced or cancelled initiator, or one that no outstanding START explains, fails the cell. The smoke command detects a running mux from every family it renders and compares MCP and GraphQL on a stable pair of readings. AD04 and AD09 record that a hold raised between two readings is not provable with a sampled gauge; that limit is not a pass/fail requirement, and a hold a reading shows still fails the cell. Resumption counts from the reading before the one that shows the discontinuity, so a recovery between the same two readings counts. AD04, AD07 and AD09 read the discontinuity, reconnect, contended-selection and retained-bid series in their pass criterion, so a gateway that does not publish one of them answers `signal_missing` and the cell does not pass. Gate and tooling change; the gateway binary is unchanged.
