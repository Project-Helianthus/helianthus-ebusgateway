## Hardware acceptance report key in the catalog spelling (catalog version 3)

The report key of the transitional hardware acceptance catalog moves from `catalogue_version` to `catalog_version` in the result schema and the report reader. Following the catalog's version rule, the renamed key is published as catalog version 3 with a new ledger entry and a recomputed result schema signature; the ledger entries of versions 1 and 2 are retained unchanged, and the catalog page states the rule. There is no alias and no dual acceptance: the reader refuses a report that carries the old key as an unknown field, and refuses a report of an earlier version by its version; such a report is read with a build of that version. Inventories, mappings, categories, vocabulary, gates and cases are unchanged. The gateway binary changes, so the affected release evidence must be renewed before the final bill of materials freeze.
