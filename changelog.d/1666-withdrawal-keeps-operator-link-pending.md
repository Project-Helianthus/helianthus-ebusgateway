## Leave a pending operator identity link pending when a child is withdrawn

A withdrawal of a child in the logger-attached PV family carries no new qualified operator identity declaration for a binding it does not observe. The declaration stays pending, the child's withdrawn records still commit, and the link of the replacement binding keeps naming the replacement inverter. A declaration that names a resource the asset does not hold leaves that same withdrawal able to commit. A removed declaration is pending as a withdrawal of the installed link. The withdrawal batch carries that removal even when a qualified declaration is pending beside it, so the removed link does not stay qualified when the child does not return, and the qualified declaration stays pending. A batch that carries any other operator link set is still refused (#1666).
